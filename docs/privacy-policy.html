AI 며느리 개인정보처리방침

시행일: 2026년 8월 21일  |  최종 수정: 2026년 8월 21일

AI 며느리(이하 "앱")는 이용자의 개인정보를 소중히 여깁니다. 본 방침은 앱이 수집하는 정보, 사용 방법, 보호 방식을 설명합니다.

1. 수집하는 정보 및 이유

  • 연락처 (READ_CONTACTS) — "딸한테 전화해줘" 같은 음성 명령을 처리하기 위해 이름·전화번호를 기기 내에서 검색합니다. 서버로 전송하지 않습니다.
  • 통화 상태 (READ_PHONE_STATE) — 수신 전화 발신자 번호를 연락처와 대조해 저장되지 않은 번호를 알려드립니다. 통화 내용을 녹음하지 않습니다.
  • SMS 수신 (RECEIVE_SMS) — 수신 문자를 기기 내에서 스팸·스미싱 패턴과 대조합니다. 문자 원문은 서버로 전송하지 않습니다.
  • 마이크 (RECORD_AUDIO) — 음성 명령을 인식하기 위해 녹음합니다. 녹음 데이터는 텍스트 변환 후 즉시 폐기됩니다. 음성 인식에 Google Speech-to-Text API를 사용합니다.
  • 카메라 (CAMERA) — 문서·우편물 사진을 촬영해 AI가 내용을 설명해드립니다. 이미지는 Google Gemini API로 분석 후 즉시 폐기됩니다.
  • 위치 (ACCESS_COARSE_LOCATION, ACCESS_FINE_LOCATION) — "근처 병원 찾아줘" 같은 업체 검색 시에만 사용합니다. 위치는 검색 쿼리에만 활용하고 저장하지 않습니다.
  • 외부 저장소 (READ_EXTERNAL_STORAGE) — Android 12 이하 기기에서 갤러리 사진 선택 시 사용합니다.

2. 기기 내 저장 데이터

앱은 아래 데이터를 기기 내 로컬 저장소(AsyncStorage)에만 저장합니다.

  • 즐겨찾기 연락처 목록
  • 비상 연락처 (이름·전화번호)
  • 대화 로그 (당일 기록, 앱 재시작 시 초기화)
  • 이상 감지 기준선 데이터 (사용 통계 기반 기준값)

이 데이터는 앱 삭제 시 함께 삭제됩니다.

3. 외부 서비스 전송

  • Google Speech-to-Text — 음성 인식. 오디오 데이터는 처리 후 Google 정책에 따라 처리됩니다.
  • Google Gemini API — 문서 이미지 분석. 이미지는 분석 후 즉시 폐기됩니다.
  • SilverLink (선택) — SilverLink 서비스에 자발적으로 연결한 경우에 한해, 이상 감지 결과(발언 요약·카테고리)를 보호자에게 알리기 위해 전송합니다. 연결하지 않으면 전송하지 않습니다.
  • Kakao 로컬 API — 업체 검색 시 위치 기반 검색 쿼리를 전송합니다.

4. 제3자 제공 금지

앱은 이용자의 개인정보를 광고·마케팅 목적으로 제3자에게 제공하거나 판매하지 않습니다.

5. 데이터 보존 기간

기기 내 저장 데이터는 앱 삭제 즉시 삭제됩니다. 외부 API(Google 등)의 처리 정책은 각 서비스의 개인정보처리방침을 따릅니다.

6. 아동 개인정보

앱은 만 14세 미만 아동을 대상으로 하지 않습니다. 아동의 개인정보를 의도적으로 수집하지 않습니다.
