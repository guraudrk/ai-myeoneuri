# PRD — B2C 전환: 구독자 1,000명 / 순수령 월 500만원

작성일 2026-08-14 · 근거 `docs/RESEARCH_2026-08-14_B2C_경쟁분석.md`
기준 versionCode 47 · 이 문서는 **다음 6개월 동안 ai-myeoneuri 저장소의 유일한 작업 기준**이다.

---

## 🎯 북극성

> **자녀가 부모 폰에 며느리를 깔고, 월 9,900원을 낸다. 이유는 "모르는 번호를 며느리가 먼저 받아주기 때문"이다.**

- 실질 손익분기 = **유료 구독자 650명 → 순수령 월 500만원** (M+12)
- 목표 = **유료 구독자 1,000명 → 순수령 월 846만원** (M+18, 안심 850 + 안심+ 150 기준)
- 결제 주체 = **자녀·보호자**. 어르신에게 결제를 요구하지 않는다.

## 🚫 이 6개월 동안 하지 않는 것

- B2B 기관 대시보드 신규 기능 (`silverlink-web-input` 쪽은 유지보수만)
- iOS 네이티브 앱 (자녀 표면은 **웹**으로 해결)
- 범용 Accessibility 자율 에이전트 (ADR-007 유지)
- 통화 자동 녹음 (ADR-008 유지) — 며느리는 녹음하지 않는다
- AI 컴패니언·감성 대화 전면 도입 (§F7의 제한된 형태만)
- 리팩터링·스택 교체

## F2 — ★ 발신자 확인·스팸 탐지 차단 (Week 5~10) — 최우선 해자

> **Play Store 포지셔닝:** "Caller ID, spam detection and blocking" (ADR-022)
> Play 정책상 anti-smishing track record 요건 없이 심사 통과 가능한 카테고리.
> F2-1(발신자 확인)이 대외 주요 기능이며, F2-2(SMS 스팸 탐지)·F2-3(통화 중 경보)은 부가 기능으로 기재한다.
>
> 근거: 2025 상반기 60대 이상이 보이스피싱 피해자의 **30.6%** (전 연령 1위, 2020년 16%의 2배).
> 스미싱 피해자의 **94%가 50대 이상**. 자녀가 부모 폰에 앱을 까는 동기 1순위.

### 설계 원칙 (타협 불가)

- **문자 원문은 절대 서버로 보내지 않는다.** 100% 온디바이스 분류
- **차단하지 않는다. 경고만 한다.** 잘못 차단하면 진짜 급한 연락을 놓친다
- **권한 없이도 앱이 정상 동작한다.** 권한 거부는 기능 축소일 뿐 앱 중단이 아니다

### F2-1. 모르는 번호 인터셉트

- 수신 통화 시 저장된 연락처 / 즐겨찾기 대조
- 미저장 번호면 **전체 화면 큰 글씨 카드**: "저장되지 않은 번호예요. 가족이 아닐 수 있어요"
- 버튼 3개: [받기] [안 받기] [딸에게 물어보기]
- "딸에게 물어보기" → `safetyAlertBridge` 재사용해 자녀에게 푸시

**수용 기준**
- [ ] 저장된 번호 수신 시 카드가 **뜨지 않는다** (오탐 0)
- [ ] 카드가 뜬 상태에서 아무것도 안 하면 시스템 기본 동작으로 넘어간다 (통화를 막지 않는다)
- [ ] 권한 거부 시 이 기능만 꺼지고 나머지는 정상

### F2-2. 온디바이스 스미싱 분류

- 규칙 엔진(정규식) + 경량 분류기 2단
- 탐지 패턴: 가족 사칭("엄마 나 폰이 고장나서"), 기관 사칭(검찰·금감원·국세청), 택배·부고·청첩장 링크, 단축 URL, 해외 발신
- 위험 문자 도착 시 어르신 폰에 큰 글씨 배너 + 자녀에게 알림
- **오탐 관리**: 자녀가 웹에서 "이건 정상이에요" 피드백 → 개인 화이트리스트 학습

**수용 기준**
- [ ] 테스트셋 100건(위험 50 / 정상 50)에서 **재현율 ≥ 0.85, 오탐률 ≤ 0.10**
- [ ] 문자 원문이 네트워크로 나가지 않는다 (네트워크 로그로 검증, 테스트로 고정)
- [ ] 분류 지연 ≤ 300ms (구형 저사양 단말 기준)

### F2-3. 통화 중 위험 발화 경보 (안심+)

- 통화 중 "계좌", "송금", "인증번호", "앱 설치" 등 위험 키워드 감지 → 진동 + 화면 경고
- **온디바이스 STT만 사용.** 통화 내용을 저장하거나 전송하지 않는다 (ADR-008 유지)

**수용 기준**
- [ ] 통화 오디오가 파일로 저장되지 않는다
- [ ] 경고가 통화를 끊지 않는다

### F2-4. 자녀 즉시 알림

- 위험 이벤트 → 자녀 푸시 + (선택) 문자
- 알림 내용에 **문자 원문을 넣지 않는다.** "위험 문자로 의심되는 메시지가 왔어요" + 웹 링크

**수용 기준**
- [ ] 위험 탐지 → 자녀 푸시 도달까지 ≤ 10초
- [ ] 형제 3인 동시 알림 (안심+)

### F2-5. Play Store 대응

- [ ] 카테고리 **생산성** 유지. 의료(Medical) 절대 금지
- [ ] 스토어 설명에 **"건강" 단어 미사용** (돌봄·안심·보안으로 대체)
- [ ] `READ_SMS` / `READ_CALL_LOG` 사용 목적 설명 문서 사전 작성 및 심사 안내에 첨부
- [ ] 개인정보처리방침에 "온디바이스 처리, 원문 미전송" 명시

## F4 — 리텐션 (Week 14~16)

> 문제: ADR-016으로 약 알림을 지운 뒤 **매일 앱을 열 이유가 없다.**

### 작업

1. **하루 한 번 먼저 말 걸기** — "오늘 전화하실 분 있으세요?" (시간은 사용자별 학습)
   - 알림 피로 방지: 응답 없는 날이 3일 연속이면 빈도를 낮춘다
2. **가족 연결 넛지** — "지은 님과 통화하신 지 5일 됐어요" → 원탭 발신
   - **이게 며느리의 성공 지표다.** AI와의 대화 시간이 아니라 가족과의 통화 횟수
3. **주간 회고 카드** — "이번 주 4번 통화하셨어요"
4. **해지 방어** — 해지 시도 시 "이번 달 위험 문자 3건을 막았어요" 표시

### 수용 기준

- [ ] D30 리텐션 기준선 대비 **+10%p 이상** 개선 (F0 대시보드로 측정)
- [ ] 알림 opt-out이 홈 화면 2탭 안에 있다
- [ ] 넛지가 하루 1회를 넘지 않는다

## F5 — 노인 특화 ASR 정확도 (Week 17~19)

> 근거: 노인 음성은 발화 속도 저하, 잦은 휴지, 불안정한 조음, presbyphonia로 범용 ASR에서 체계적으로 성능이 떨어진다(다수 논문 일치).
> 현재는 error 11 재시도로 증상만 덮고 있다.

### 작업

1. **개인화 어휘 바이어싱** — 사용자 연락처 이름·관계어·거주 지역 상호를 인식 힌트로 주입
2. **적응형 침묵 타임아웃** — 사용자별 평균 발화 속도를 학습해 타임아웃을 늘린다
3. **재발화 학습 루프** — 실패→재발화→성공 쌍을 로컬 축적, 개인 사전 강화 (`auditLog` 구조 재사용, 로컬 전용)
4. **은혜로운 폴백** — 2회 실패 시 "다시 말씀해 주세요"를 반복하지 않고 **즐겨찾기 3인 큰 버튼**으로 전환

### 수용 기준

- [ ] **FUSR가 F0 기준선 대비 +15%p 이상** 상승
- [ ] 개인 사전이 기기 밖으로 나가지 않는다
- [ ] "다시 말씀해 주세요"가 연속 3회 나오는 경로가 코드상 존재하지 않는다

## F6 — 화면 가이드 모드 (Week 20~23, 안심+)

> 슈워요는 "설명"만 하고, 자율 GUI 에이전트는 위험하다. 그 사이의 빈자리.

### 원칙

- **며느리가 대신 누르지 않는다. 어디를 누를지 화살표로 알려준다.**
- ADR-007(LLM은 계획만) · PRODUCT_SPEC "범용 Accessibility Agent 제외" 유지
- 금융 보안 화면 · OTP · 비밀번호 입력 화면은 **코드 레벨 차단** (ADR-009)

### 작업

1. Accessibility Service로 화면 트리 읽기 (스크린샷 전송 없이 텍스트 트리만)
2. Gemini에 "지금 화면에서 <목표>를 하려면 어디를 눌러야 하나" 질의
3. 해당 요소 위에 **큰 화살표 오버레이 + TTS 안내**
4. 지원 시나리오는 **화이트리스트 방식**으로 시작 (은행 앱 잔액 조회, 병원 예약, 열차 예매)
5. 차단 목록: 로그인/OTP/이체/비밀번호/카드번호 입력 화면 감지 시 즉시 가이드 중단

### 수용 기준

- [ ] 차단 화면 목록에서 오버레이가 **절대** 뜨지 않는다 (테스트로 고정)
- [ ] 며느리가 자동으로 탭하는 코드 경로가 존재하지 않는다
- [ ] 화면 텍스트 트리에서 계좌번호·주민번호 패턴을 마스킹한 뒤 전송한다
- [ ] 사용자가 언제든 한 번의 탭으로 가이드를 끌 수 있다

## F7 — 가족 컨텍스트 메모리 (Week 24~26)

> 클로바 케어콜의 "기억하기"에 대응. 단, **AI가 친구가 되는 방향으로 가지 않는다.**

### 근거와 제약

4개국 2,000명 12개월 종단 연구에서 소셜 챗봇 사용 증가는 **외로움 증가를 예측**했다. 21일 RCT(N=183)에서도 전반적 효과는 없었다. **정서적 의존을 만드는 설계는 사용자에게 해롭고, 장기적으로 해지 사유가 된다.**

### 작업

1. **가족 관계 그래프** — 관계·통화 주기·최근 언급 주제를 로컬 우선 저장
2. **멀티턴 대화** — `intentParser.ts`를 단발 호출에서 짧은 세션 컨텍스트 유지로 확장. "누구라고요?" 되묻기 지원
3. **자녀 리포트 재료 공급** (F3-3)
4. **되돌리기 설계** — 대화가 길어지면 "딸한테 전화해서 얘기해 보실래요?"로 유도

### 수용 기준

- [ ] 멀티턴 세션에서 프롬프트 인젝션 방어(`promptInjection.ts`)가 여전히 작동한다 (컨텍스트 누적이 방어를 뚫지 않는다)
- [ ] 세션 컨텍스트가 5턴 또는 3분 후 만료된다
- [ ] **"며느리와의 대화 시간"을 성공 지표로 대시보드에 올리지 않는다.** 대신 "가족 통화 횟수"를 올린다
- [ ] 건강·의료 조언으로 읽힐 수 있는 응답을 생성하지 않는다 (Play Store 제약)

## 원가 규율 (F1 완료 즉시 적용)

Gemini Live 기준 **입력 $0.005/분 + 출력 $0.018/분**. 하루 5분 대화 × 30일 = **약 4,800원/월** — ARPU를 통째로 먹는다.

- 기본 경로 = 온디바이스 STT + Gemini Flash **텍스트** (현재 구조 유지)
- 실시간 음성 = **안심+ 전용, 월 30분 상한**
- 상한 도달 시 저비용 경로로 **자동 강등** (기능 중단이 아니라 품질 하향)
- `ai_cost_incurred` 이벤트로 사용자별 원가를 상시 추적. 상위 5% 사용자를 매주 확인
