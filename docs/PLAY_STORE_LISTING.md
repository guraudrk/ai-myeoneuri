## 긴 설명 (4000자 이하)

```
AI 며느리는 어르신 부모님을 위해 자녀가 설치해 드리는 앱입니다.

📱 모르는 번호가 오면 며느리가 먼저 알려드려요
저장되지 않은 번호로 전화가 오면 큰 글씨로 알려드립니다.
[받기] [안 받기] [딸에게 물어보기] — 어르신이 판단할 수 있도록 도와드려요.

📩 수상한 문자를 감지합니다
"검찰청에서 연락드립니다", "택배 미수령 안내" — 수상한 패턴의 문자가 오면 경보를 드립니다.
문자 원문은 절대 외부로 보내지 않습니다. 기기 안에서만 처리합니다.

🗣️ 말로 전화하세요
"딸한테 전화해 줘" — 말씀하시면 연락처를 찾아 전화해 드립니다.
작은 글씨를 볼 필요 없이 그냥 말씀만 하시면 됩니다.

📸 종이 내용을 읽어드려요
청구서, 안내문, 처방전 — 카메라로 찍으면 내용을 읽어드립니다.

👨‍👩‍👧 가족과 연결됩니다 (SilverLink 연동)
위험 신호를 감지하면 자녀에게 즉시 알립니다.
자녀는 별도 대시보드에서 부모님 상태를 확인할 수 있습니다.

---

✅ 보안 원칙
• 통화 내용을 녹음하거나 저장하지 않습니다
• 문자 원문을 서버로 보내지 않습니다
• 권한을 거부하셔도 나머지 기능은 정상 동작합니다
```

> 글자 수: 약 550자 (4000자 한도 내, 추가 내용 권장)

## 스크린샷 촬영 순서 (권장)

1. 홈 화면 (마이크 중앙, 큰 글씨)
2. 모르는 번호 수신 화면 (Caller ID 카드)
3. 스팸 의심 문자 경보 화면
4. 연락처 전화 확인 카드
5. 설정 화면 (자녀·관리자용 탭)
