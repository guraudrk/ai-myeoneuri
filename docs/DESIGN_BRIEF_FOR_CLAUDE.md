# AI 며느리 — Claude Design 브리프

## 한 줄 요약

어르신(60~80대)이 음성으로 전화·검색·질문을 하는 Android 앱.
**"어르신이 쓰지만 자녀가 봐도 세련된 앱"** 이 목표다.
Toss·카카오 수준의 디자인 품질 + 어르신 가독성(큰 글씨, 큰 터치 영역, 명확한 계층).

---

## 이 앱의 해자 (경쟁 우위)

> **"어르신을 위한 제미나이(Gemini) 종합 비서"** — 일반 AI 앱은 어르신이 쓰기 어렵다.

이 앱의 핵심 차별점:
1. **마이크 버튼 하나** — 설치하고 누르기만 하면 된다. 음성 명령 하나로 전화·검색·질문 전부 처리.
2. **어르신 특화 AI 답변** — Gemini에 "할머니·할아버지 말투, 짧은 문장, 쉬운 단어, 핵심 먼저" 시스템 프롬프트를 적용. 일반 AI 앱의 답변(영어 섞인 전문용어, 긴 설명)과 다르다.
3. **종합 비서** — 업체 찾기, 지인 전화, 약 알림, 환율·날씨·잡다한 질문, 앱 실행, 안전 신호 감지까지 음성 하나로.

**디자인에서 해자를 보여주는 방법:**
- AI 비서임을 첫 화면에서 바로 느낄 수 있어야 한다 → 단순 버튼 앱처럼 보이면 안 됨
- "말하면 뭐든 된다"는 가능성이 시각적으로 전달되어야 함
- 어르신도 쓸 수 있다는 신뢰감(큰 글씨·명확한 계층)과 자녀가 "좋은 앱"으로 느끼는 세련됨이 동시에 있어야 함

---

## 개발 환경 제약

- **React Native (Expo bare workflow)** — 웹 CSS 아님, RN `StyleSheet` 기준
- 색상·폰트 크기·여백·둥근 모서리 값은 `src/components/tokens.ts` 하나에서 관리
- 모든 디자인 제안은 **RN StyleSheet 속성**으로 표현 (`px` 단위 없이 숫자만)
- 외부 폰트 라이브러리 추가 가능 (`expo-font`), 단 구글 폰트 기준

## 사용자

| 역할 | 설명 |
|---|---|
| **주 사용자** | 어르신 (60~80대). 앱 설치·설정은 자녀가 해줌. 본인은 마이크 버튼만 누름. |
| **보조 사용자** | 자녀·며느리. APK 설치 후 어르신 폰에 올려줌. 가끔 결과 화면을 같이 봄. |

## 화면 목록 & 현재 상태

### 1. 홈(idle) — 가장 중요한 화면

```
┌─────────────────────────────────┐
│  [네이비 히어로 영역 #0F1F4B]    │  flex 0.55
│  "AI 며느리" (배지 텍스트)       │
│  "무엇을                        │
│   도와드릴까요?"  (32px, white)  │
│                                 │
│       ●  (마이크 버튼 144px)     │
│    "눌러서 말하기"               │
│                                 │
│  🆘  긴급 SOS  (빨간 알약 버튼) │
└─────────────────────────────────┘
┌─────────────────────────────────┐
│  [흰 시트 영역]                  │  flex 0.45 (스크롤)
│  즐겨찾기 목록 (카드 행)         │
│  약 알림 목록 (카드 행)          │
│  ─── 직접 입력 ───              │
│  [텍스트 입력창]                 │
│  [실행하기 버튼]                 │
│  + 약 복용 알림 추가             │
└─────────────────────────────────┘
```

**현재 문제점:**
- 히어로 영역과 시트 영역의 비율(55/45)이 어색함. 마이크 버튼 주변 여백 부족.
- "직접 입력" 섹션이 주목적(마이크)과 섞여서 계층이 불명확.
- 즐겨찾기/알림 목록이 있을 때 시트가 너무 빡빡함.

---

### 2. 업체 검색 결과 화면

업체 카드 (반복):
```
┌─────────────────────────────────┐
│ 🍗  강남치킨               1.2km│  헤더 행
│     치킨/닭강정                 │
├─────────────────────────────────┤
│ 📍  서울 강남구 역삼동 123      │  주소
├─────────────────────────────────┤
│ 📞  02-1234-5678         🗺지도 │  전화번호 박스 (회색 배경, 26px 볼드 블루)
├─────────────────────────────────┤
│     탭하면 전화 연결  ›          │  파란 바 (CTA)
└─────────────────────────────────┘
```

하단: `[🗺 카카오맵에서 더 보기]` 테두리 버튼

**현재 문제점:**
- 카드가 세로로 길어서 한 화면에 1~1.5개밖에 안 보임
- 전화번호 박스 배경(#F8FAFB)과 카드 배경(#FFF)의 차이가 너무 미묘
- 거리 뱃지 크기와 위치가 어색함

### 3. 일반 질문 답변 화면

```
┌─────────────────────────────────┐
│ 🎤  "오늘 달러 환율 어때?"       │  질문 원문 (이탤릭, 회색)
│ ─────────────────────────────── │
│                                 │
│  Gemini 답변 텍스트가            │
│  여기에 길게 표시됨              │
│                                 │
│        홈으로 돌아가기           │
└─────────────────────────────────┘
```

**현재 문제점:**
- 답변이 길어질 때 레이아웃이 무너짐 (패딩 부족)
- Gemini 답변 폰트(20px 500)가 너무 평범함. "AI가 말하는 느낌"이 없음.

### 5. 전화 확인 화면

업체 전화 확인:
- 🏪 이모지 (80×80 원), 업체명, 주소
- "지금 전화할까요?"

- [전화하지 않을게요] 고스트 버튼

## 디자인 요청사항

### 목표 분위기
- **Toss** — 큰 텍스트, 풍부한 여백, 부드러운 그림자, 명확한 CTA
- **카카오** — 친근함, 노란/파란 포인트, 직관적 아이콘
- **어르신 친화** — 글자 크기 절대 줄이지 말 것. 터치 영역 56px 이상 유지.

### 구체적 요청

1. **컬러 팔레트 재설계**
   - 현재 `primary: #2563EB` (차가운 블루) → 더 따뜻하고 신뢰감 있는 블루 또는 대안 제시
   - 홈 히어로 `navyDeep: #0F1F4B` → 더 생동감 있는 색으로 (너무 어둡고 무거움)
   - 안전 알림 빨간색 팔레트

2. **타이포그래피**
   - 현재 시스템 기본 폰트 → 한국어 가독성 좋은 구글 폰트 추천 및 적용 방법
   - 각 용도별 `fontSize` / `fontWeight` / `lineHeight` 값 제안

3. **홈 화면 레이아웃 재구성**
   - 마이크 버튼 중심 설계. 더 크게, 더 강조.
   - 즐겨찾기/알림/입력창을 하단 시트(bottom sheet)처럼 보이게

4. **업체 카드 개선**
   - 한 화면에 2개 이상 보이도록 세로 길이 압축 방법
   - 전화번호가 한눈에 들어오게 (현재보다 더 강조)

5. **버튼 시스템**
   - CTA 버튼, 고스트 버튼, 위험 버튼 3종 스타일 정의

6. **앱 이름/브랜딩**
   - "AI 며느리" 로고타입 또는 워드마크 텍스트 스타일 제안

### 납품 형식

아래 형식으로 결과물을 주세요:

```ts
// tokens.ts 전체 교체본
export const Colors = { ... }
export const FontSize = { ... }
// ... 나머지 토큰들
```

그리고 화면별로 변경이 필요한 StyleSheet 속성값만 명시.
전체 파일 재작성 말고, **변경되는 값만 diff 형태**로.

## 현재 스크린샷 설명 (실기기 테스트 기준)

- 홈: 네이비 상단 + 연회색 하단. 마이크 버튼은 중앙에 파란 원.
- 업체 카드: 흰 카드, 파란 전화번호, 파란 CTA 바.
- 전반적으로 깔끔하지만 **에너지가 없고 너무 차가운 느낌**.
- 어르신용이라는 느낌이 너무 강해서 자녀가 봤을 때 "좋은 앱"으로 느껴지지 않음.
