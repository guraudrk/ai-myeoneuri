## 세션 1: B-9 종이 읽기 개선 + TTS 끊김 수정

### 막혔던 지점

- Gemini 응답이 "이" 글자 중간에서 잘렸다 → `maxOutputTokens: 500`이 원인이었음.
  처음에는 TTS 문제인 줄 알고 `maxSentences`를 10 → 20으로 올렸으나 근본 해결 안 됨.
  "출력 텍스트는 끝까지 잘 나와, TTS가 끊겨"라는 피드백으로 두 문제가 다름을 확인.

- TTS도 실제로 끊겼다 → `maxSentences` 기본값 4가 너무 짧았음.
  사용자 피드백: "답변의 길이 상관없이 처음부터 끝까지 읽어줬으면" → `Infinity`로 변경.

### 왜 `system_instruction`(ELDERLY_SYSTEM_PROMPT)을 제거했는가

ELDERLY_SYSTEM_PROMPT에 "4문장 이내" 규칙이 있었다. 이 프롬프트가 `readPaperWithGemini`에서도 적용되면서 문서 분석 품질이 저하됐다. 일반 대화(4문장 이내가 적절)와 문서 분석(날짜·금액·해야 할 일을 다 설명해야 함)은 길이 요건이 다르다. 제거 후 분석 품질 대폭 개선.

### 변경 파일

- `src/features/intent/intentParser.ts`: `readPaperWithGemini` — `maxOutputTokens` 제거, `system_instruction` 제거, 새 PROMPT 작성
- `app/(tabs)/index.tsx`: paper_result 화면 리디자인(파란 헤더 + 카드), 자동 TTS `maxSentences: Infinity`

## 세션 2: 알람 기능 완전 제거 (ADR-022)

### 결정 이유

설정 화면에서 알람 토글이 SilverLink 연결 게이트 뒤에 숨어 있었다. "실버링크 상관없이 할 수 있게 해"라는 요청 → 알람 설정을 별도 모달로 분리 시도 → QA 중 "알람 기능 아예 없애줘"로 방향 전환.

기관 방문 판매에서 어르신 알람 기능은 주요 가치가 아니다. 제거해서 앱을 단순화하고 코드 복잡도를 낮추는 게 맞다고 판단.

### 변경 파일

- `app/(tabs)/index.tsx`: `dailyGreetingEnabled` 상태, DailyGreetingService import, F4-1 토글 블록 전부 제거

## 세션 3: B-8 이상 감지 → 가족 알림 SilverLink 비의존 처리

### 문제 정의

기존 `reportSafetyConcernToSilverLink`는 `if (!link.linked) return;` — SilverLink 미연결 시 아무것도 안 했다. SilverLink 없이도 이상 감지 시 가족에게 알리고 싶다는 요청.

### 왜 직접 전화 다이얼러인가

SMS는 SEND_SMS 권한 필요 → Play Store 심사 부담. 자동 전화 발신은 너무 공격적. 다이얼러 오픈(Linking.openURL `tel:xxx`)은 권한 없이 동작하고 사용자 확인을 거친다. Alert로 "전화할까요?" 물어보고 Yes 시 다이얼러 실행 — 어르신이 최종 판단.

### 막혔던 지점

비상 연락처를 "즐겨찾기 첫 번째"로 쓸까 고민했으나, 즐겨찾기는 자주 전화하는 사람이고 비상 연락처는 별도 개념이다. AsyncStorage에 독립 저장하는 방식 채택.

### 변경 파일

- `src/features/safetyLink/emergencyContactService.ts` 신규: 비상 연락처 CRUD
- `src/features/safetyLink/safetyAlertBridge.ts`: 미연결 분기 추가 — `getEmergencyContact` 조회 → Alert 표시 → 다이얼러 실행
- `app/(tabs)/index.tsx`: 미연결 설정 모달에 비상 연락처 설정 UI 추가

### 배운 것

`Alert`는 React Native 서비스 레이어(비컴포넌트 파일)에서도 호출할 수 있다. 단, Android에서는 Alert가 Activity context에 묶여 있어 앱이 백그라운드 상태면 표시되지 않을 수 있다. 이상 감지가 포그라운드에서만 동작(UsageStatsAdapter는 앱이 켜진 상태에서 실행)하므로 이 경우 문제 없다.
