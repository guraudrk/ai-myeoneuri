## Required workflow

For multi-step work:

1. Read the relevant source-of-truth documents.
2. Inspect the current repository and Git status.
3. Define objective, scope, constraints, validation, and stop conditions.
4. Plan the smallest runnable slice.
5. Implement with minimal unrelated changes.
6. Run risk-appropriate validation.
7. Review the diff.
8. Update plan and decisions when necessary.
9. Report evidence and next priority.

Read the full operating manual only for multi-step, architectural, risky, or autonomous work.
